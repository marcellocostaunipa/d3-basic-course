# Lesson 17 — More instances of Pinned Scrollytelling 

## Prompt

Devo ottimizzare il codice per evitare di ripetere linee. Ad esempio, cosa dovrei fare per inserire un nuovo JSON, un nuovo SVG, per inserire un nuovo elemento pinned nella pagina HTML? È possibile scrivere una funzione a cui posso passare: l'url del JSON, l'url dell'SVG, il nome dello step che deve coincidere con il valore del campo "id" del JSON, il valore degli attributi id dell'HTML e dell'SVG? Valori inoltre che devono essere progressivi?
